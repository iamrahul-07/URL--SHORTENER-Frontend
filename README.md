# 🔗 URL Shortener - Frontend

A responsive frontend for a URL Shortener application built with React.js. Users can generate short URLs, copy them instantly, and access previously shortened links through a clean and modern interface.

## 🚀 Live Demo

🌐 https://url-short1.netlify.app/

## 🔗 Backend Repository

https://github.com/iamrahul-07/URL-SHORTENER-Backend

---

## ✨ Features

- Generate Short URLs
- Copy URL with One Click
- Responsive Design
- Error Handling
- Modern User Interface

---

## 🛠 Tech Stack

- React.js
- Tailwind CSS
- Axios
- React Router

---

## ⚙ Installation

```bash
npm install
npm run dev
```

---

## 📚 Purpose

This project was built as a learning project to understand frontend-backend communication, REST APIs, and deployment using Netlify.
